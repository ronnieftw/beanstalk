Beanstalk

SETUP · ONCE

This writes the two files that hold your settings: secrets.yaml for the panel, beanstalk.env for the bridge.

This page runs entirely in your browser. Nothing is sent anywhere, and it works with the network off. Open the file in a text editor if you would rather check that yourself.

The panel

Shown at the top of the panel, and in the setup instructions the panel displays if it loses wifi. Whatever they call you.

Where you set the panel up and flash it.

A second wifi SSID if needed. Leave blank if not.

When the panel can find no known wifi it raises its own network, so whoever is with it can put it back on wifi from a phone. You will be reading this out over the phone, so keep it short and speakable.

Guards firmware updates sent over wifi. Never typed by hand.

The broker

Both ends dial out to a hosted MQTT broker, so neither your network nor the panel's has to accept incoming connections. HiveMQ Cloud's free tier is enough. Make two credentials, one for each end, so either password can be changed later without taking both ends down.

Give both credentials publish and subscribe. On HiveMQ's free tier that is a per-credential setting.

Bare hostname. Do not include https:// or a port.

Telegram

Install the Telegram app and make an account if you do not have one. Everything you send to the panel goes through a bot you own, inside Telegram.

In Telegram, message @BotFather and send /newbot. It asks for a name and a username, then sends a long reply. The token is the one line in it that looks like 8123456789:AAHk3x... — paste the whole token string, including the digits before the colon.

Leave this blank. On first run the bridge prints a pairing code, and the chat that sends it is the only chat the bridge answers. Fill it in only if you already know the number.

The bridge

Whatever you type after ssh. Nothing connects from here; it only fills in the commands at the bottom of this page.

Must differ from the panel's, which is sticky1234. Two MQTT clients sharing an id knock each other offline continuously.

The panel reports in every five minutes. Silence past this means it is off, flat, or off wifi.
